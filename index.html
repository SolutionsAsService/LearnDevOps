LearnDevOps
CI/CD GitOps IaC Microservices Monitoring

Five DevOps tracks, one path a change takes

The tracks

  • CI/CDAutomated build, test and deploy, with rollback to a stable release.
  • GitOpsDeclarative Kubernetes state in Git, synced with ArgoCD or Flux.
  • IaCTerraform infrastructure with remote state, locking and workspaces.
  • MicroservicesFive service examples: AuthService, DistributedSystems, E-Commerce, ProductCatalog, ServerlessApplications.
  • MonitoringPrometheus and Grafana for logs, metrics and alerts.

How to start

  1. Clone the repository: 
    git clone https://github.com/SolutionsAsService/LearnDevOps
cd LearnDevOps
  2. Pick a track above and open its readme.md for the use case and the security and DevOps notes.
  3. Run the example files in that track's folder, such as CI-CD/deploy.yml or Monitoring/prometheus.yml.
