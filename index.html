Five DevOps tracks, each with its own readme

Hands-on examples for delivery, infrastructure, services and observability.

The five tracks

  • CI/CD

    Automates building, testing and deploying an app, with secrets in GitHub Secrets and rollback.

  • GitOps

    Declares Kubernetes application state in Git and syncs it with ArgoCD or Flux.

  • Infrastructure as Code

    Provisions cloud infrastructure with Terraform, with remote state and locking.

  • Microservices

    Five service examples: AuthService, ProductCatalog, E-Commerce, ServerlessApplications and DistributedSystems.

  • Observability & Monitoring

    Uses Prometheus and Grafana to watch logs, metrics and traffic, with alerts.

How to start

  1. Clone this repository and change into it: 
    git clone <repository-url>
cd LearnDevOps
  2. Open the readme in the track you want, for example IaC/readme.md.
  3. Read its use case and considerations, then run the code in that folder.
