# LearnDevOps

LearnDevOps is a set of hands-on DevOps examples. Each track covers one practice, with a readme that gives a use case, the security and DevOps considerations, and the code that goes with it.

## The five tracks

- **[CI/CD](CI-CD/readme.md)**: automated build, test and deploy, with secrets in GitHub Secrets, dependency scanning and rollback.
- **[GitOps](GitOps/readme.md)**: Kubernetes application state declared in Git and synced with ArgoCD or Flux.
- **[Infrastructure as Code](IaC/readme.md)**: cloud infrastructure provisioned with Terraform, with remote state and locking.
- **[Microservices](Microservices/)**: five service examples (AuthService, ProductCatalog, E-Commerce, ServerlessApplications, DistributedSystems).
- **[Observability and Monitoring](Monitoring/readme.md)**: logs and metrics with Prometheus and Grafana, plus alerting.

## How to use it

1. Clone the repository and change into it.
2. Open the readme of the track you want to learn.
3. Read the use case and considerations, then run the code in that folder.
